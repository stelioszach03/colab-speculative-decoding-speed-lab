# arXiv Pre-Submission Checklist

- [x] Uses source submission (`.tex` project), not PDF-only
- [x] Includes `main.tex`
- [x] Includes bibliography input (`references.bib`) and uses `\\bibliography{references}`
- [x] Includes all data files referenced by `main.tex` (`data/*.csv`)
- [x] Local compile passes from clean source folder
- [x] Generated `arxiv_source.zip`

## Metadata to verify on arXiv form
- Title and abstract match final manuscript
- Authors and affiliation details
- Correct primary category
- Comments field (optional): mention Colab/A100 empirical study
